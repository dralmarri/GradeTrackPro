# خطة التنفيذ

## 1) قاعدة البيانات (migration واحدة)

**جدول `courses`** — إضافة:
- `bonus_enabled` boolean default `true` — تفعيل/تعطيل البونص لكل مقرر
- `custom_components` jsonb default `'[]'` — مصفوفة مكونات إضافية، كل عنصر: `{ key: string, label: string, max: number }` (حد أقصى 5)

**جدول `students`** — إضافة:
- `custom_scores` jsonb default `'{}'` — مفتاح = key المكوّن، قيمة = الدرجة

## 2) صفحة الإعدادات (`SettingsPage.tsx`)

قسم جديد **"إعدادات المقررات"** بأكورديون — لكل مقرر عنصر قابل للفتح يحتوي:

- **تبديل البونص** (مُفعّل/مُعطّل) — يحلّ محل الإعداد العام
- **الدرجات القصوى وأسماء المكونات** (6 صناديق: بونص، اختبار أول، ثاني، نهائي، مشاركة، واجب) — اسم قابل للتعديل + الدرجة القصوى
- **المكونات المخصصة** — قائمة + زر "إضافة مكوّن" (حد 5)، كل مكوّن: اسم + درجة قصوى + زر حذف
- زر "حفظ" لكل مقرر

## 3) نافذة "إدارة الطلبة والدرجات" (`CourseStudentsDialog.tsx`)

- **حذف** قسمَي: تبديل البونص + الدرجات القصوى
- **الإبقاء** على: إضافة/حذف الطلبة + استيراد Excel
- تحديث العنوان إلى "إدارة الطلبة" فقط

## 4) صفحة الدرجات (`ExamsPage.tsx`)

- إضافة تبويبات للمكونات المخصصة من `course.customComponents`
- تخزين قيم المكونات المخصصة في `student.customScores[key]`
- تحديث الاستيراد من Excel ليدعم المكونات المخصصة

## 5) صفحة النتائج (`StudentStatus.tsx`)

- إخفاء عمود البونص كلياً عندما `course.bonusEnabled === false`
- استبعاد البونص من حساب المجموع عند التعطيل
- إضافة أعمدة للمكونات المخصصة + ضمّها في حساب الإجمالي

## 6) صفحة الحضور (`AttendancePerLecture.tsx` + `BonusTable.tsx`)

- استبدال `useBonusEnabled` العام بقراءة `course.bonusEnabled` من المقرر الحالي
- إبقاء `useBonusEnabled` كـ fallback أو حذفه (سأحذفه لتنظيف الكود)

## 7) ملفات أخرى متأثرة

- `types/student.ts` — إضافة `Course.bonusEnabled`, `Course.customComponents`, `Student.customScores`
- `hooks/useCourses.ts` — تحميل/حفظ الحقول الجديدة
- `lib/excel.ts` — تصدير المكونات المخصصة في Excel
- ترجمات `lib/translations.ts` — مفاتيح جديدة (إعدادات المقررات، إضافة مكوّن، إلخ)

## ملاحظات

- القيم القديمة المحفوظة في البونص تبقى في قاعدة البيانات عند التعطيل (آمن للتراجع)
- المكونات المخصصة لها `key` فريد تلقائي (مثل `custom_1`, `custom_2`) لتجنّب تعارض الأسماء عند إعادة التسمية
- جميع الحدود (الدرجة بين 0 و max) تنطبق على المكونات المخصصة أيضاً
