# GradeTrackPro v2 — نظام تصحيح الاختبارات (OMR / ZipGrade-like)

> فرع منفصل `v2`. لا يمسّ النسخة المنشورة على `main`.

## الهدف
إضافة نظام لتصحيح اختبارات الاختيار من متعدد بتصوير ورقة الإجابة بالكاميرا،
ثم رصد الدرجة تلقائياً في صفحة الطالب داخل GradeTrackPro — بأسلوب مشابه لـ ZipGrade
(وقد يكون أفضل).

## المسار التقني المعتمد
- **معالجة الصورة داخل الجهاز** عبر OpenCV.js (مجاني، دون إنترنت، خصوصية كاملة).
- **التطبيق يولّد ورقة إجابة قابلة للطباعة** فيها علامات محاذاة (registration marks)
  لضمان دقة المسح.

## المكوّنات (Phases)

### Phase 1 — نموذج البيانات + ورقة الإجابة  ← (نبدأ هنا)
- `src/types/exam.ts` — تعريف الاختبار، الأسئلة، مفتاح الإجابة، النتائج.
- مولّد ورقة إجابة قابلة للطباعة (HTML print) مع:
  - علامات محاذاة في الأركان الأربعة.
  - مربّع رقم الطالب (bubbles للأرقام).
  - شبكة فقاعات الأسئلة (أ ب ج د / A B C D E).

### Phase 2 — إعداد الاختبار ومفتاح الإجابة
- واجهة لإنشاء اختبار: عدد الأسئلة، عدد الخيارات، الدرجة القصوى.
- إدخال مفتاح الإجابة الصحيحة.
- الربط بمقرر/تبويب اختبارات موجود.

### Phase 3 — المسح بالكاميرا (OpenCV.js)
- التقاط صورة الورقة (@capacitor/camera على الجوال، أو input file على الويب).
- اكتشاف علامات المحاذاة وتصحيح المنظور (perspective warp).
- اكتشاف الفقاعات المظللة لكل سؤال.
- مطابقة رقم الطالب.

### Phase 4 — التصحيح والرصد
- مقارنة إجابات الطالب بمفتاح الإجابة → حساب الدرجة.
- عرض مراجعة (صح/خطأ لكل سؤال) مع إمكانية التصحيح اليدوي.
- إضافة الدرجة تلقائياً إلى صفحة الطالب (exam1/exam2/…/custom).

### Phase 5 — تحسينات
- مسح دفعة أوراق متتالية.
- تصدير تقرير النتائج.
- إحصائيات (أصعب سؤال، متوسط الدرجات).

## قرارات مؤجّلة
- تخزين صور الأوراق (الأرجح: لا نخزّنها للخصوصية — نعالج ونتلف).
- شكل مربّع رقم الطالب (أرقام مدنية؟ تسلسلي؟).
